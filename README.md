# Famous People Database

This repository contains a SQL database for a Khan Academy seminar project.

## Tables

- **famous_people**: Contains famous people, their age, profession, marital status, and spouse ID.  
- **movies**: Contains movies and their actors.  
- **songs**: Contains songs and their singers.  
- **books**: Contains books and their authors.  

## Project Purpose

The project aims to create a small database of famous people and demonstrate relationships between tables using `JOIN`.  
Example questions you can answer with this database:  
- Which movies has each actor appeared in? Are they married to each other?  
- What songs has each singer written?  
- What books has each author written?  
- How are fictional characters related? Which books do they appear in?  

## Usage

1. Import the `FamousPeopleDB.sql` file into your SQL environment.
2. Run queries to explore the data and relationships.
